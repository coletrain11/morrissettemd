Set up the bay

Get all three devices online first (see Network below), then scan each code with the iPhone for that angle.

Room
····

Each phone listens for the sound of impact. Set its trigger line just above the room noise, then make a practice hit. If it misses, lower the line.

Network: bay Wi-Fi

  1. Join the iPad and both iPhones to the same Wi-Fi.
  2. Scan the codes above. Each camera card shows how it connected.
  3. “Local network” is best. If a camera says “Relay”, or never connects, the Wi-Fi blocks devices from talking to each other. Use a hotspot instead.

Network: no usable Wi-Fi

  1. Turn on Personal Hotspot on one iPhone (it can be one of the cameras).
  2. Join the iPad and the other iPhone to that hotspot. Video stays on the hotspot; only the brief handshake uses cellular data.
  3. If devices can't share a hotspot, each can use its own cellular data with a relay server below.

Relay server (optional)

For cellular-only setups. Paste the “ICE servers array” from a free Metered Open Relay account. It's saved on this iPad and carried to the phones in the QR codes.
